## Definitions

- **Accuracy:** share of labelled items whose returned label equals the reference label.
- **Macro-F1 (fixed):** per-class F1 averaged over every class in the field's label space; a class that never occurs scores 0. **Macro-F1 (union)** is the `summary.json` definition, averaged over classes present in the reference or predicted labels.
- Accuracy and macro-F1 are computed at full precision and rounded once for display; `summary.json` stores the same values rounded to 4 decimals.
- **Top-label ECE:** expected calibration error of the top-label probability; equal-width uses 15 bins on [0, 1] (first bin closed below), equal-mass uses 15 groups of near-equal size after a stable sort, using `numpy.array_split`, so the first n mod 15 groups hold one extra item.
- **ECE on reported `confidence`:** the same equal-width estimator applied to the adapter's `confidence` field. Adapters define that field differently (see confidence semantics below); it is a comparison column only.
- **Log loss:** mean negative log probability of the reference label, floored at 1e-12. **Brier:** multiclass Brier score over the label space.
- **AURC:** area under the risk-coverage curve, items ranked by top-label probability (highest first, ties in pack order).

## What the pack can and cannot verify

- `replay_scores.py verify` recomputes every value stored in each `summary.json` task block except run metadata (`adapter`, `cached_items`, `dataset`, `memory`, `model_id`, `new_items`, `prompt_version`, `task`, `wall_seconds`), and compares it at stored precision.
- Query-segmentation items sampled from ORCAS-I carry the stratum `orcas_i`. The summaries break their accuracy out by ORCAS-I category; the pack does not carry that category, so those entries are verified in aggregate (item and correct counts summed over categories), not one by one.
- Token counts and cost are compared only where a summary stores them.
- Latency values are recomputed from each prediction's recorded `elapsed_ms`. They describe each run on its own hardware and batch size, not a controlled latency comparison.
- The pack holds no query or product text, so prompts, model inputs and judge rationales cannot be inspected from it.
