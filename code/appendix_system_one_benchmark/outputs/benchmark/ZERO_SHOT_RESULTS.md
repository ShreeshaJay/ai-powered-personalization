## Labels

- Compatibility, query segmentation and brand/category: dual-judge field consensus. A field on which the two judges disagreed is withheld and not scored, so n differs by field.
- ESCI: a class-balanced slice of 8,000 US test pairs (2,000 per E, S, C and I) scored against the ESCI human labels.

## Definitions

- **Accuracy** and **macro-F1** use the committed metric definitions, computed from the pack and rounded once for display; each `summary.json` stores the same values rounded to 4 decimals. Macro-F1 averages per-class F1 over the classes that occur in the reference or the predicted labels.
- **Top-label ECE** uses the probability each model assigned to the label it returned, taken from its probability vector, and counts an item as correct when that label equals the reference. Equal-width: 15 bins on [0, 1], the first closed below. Equal-mass: items stably sorted by that probability and split into 15 groups of near-equal size, using `numpy.array_split`, so the first n mod 15 groups hold one extra item.
- **ECE on reported `confidence`** applies the same 15-bin equal-width estimator to the adapter's `confidence` field instead of the probability vector. Adapters define that field differently, so this column is not a calibration measure; it is printed for comparison only. `summary.json` stores the same quantity with 10 bins under `ece`.
- Fields in which one class holds at least 99% of the labelled items are degenerate and are listed separately, below the main table.
